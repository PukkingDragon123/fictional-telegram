Bundled pixel fonts
===================

Galmuri11.subset.woff2       (body / dialogue font, --font-body, 'TBME Body')
Galmuri11-Bold.subset.woff2  (title / numbers / logo font, --font-title, 'TBME Title', 'TBME Logo')

  Galmuri by Lee Minseo (quiple), https://github.com/quiple/galmuri
  Taken from the npm package galmuri@2.40.3.
  Licence: SIL Open Font License 1.1 (no Reserved Font Name), full text in
  Galmuri-OFL.txt next to this file.

  These are Modified Versions as the OFL allows: subset to Latin + the symbols
  the game uses, and the ♂ / ♀ glyphs redrawn (and added to the Bold cut).
  build-galmuri-subset.py in this folder rebuilds them from the original TTFs.

  Credit (title screen): "Font: Galmuri11 by Lee Minseo (quiple), SIL OFL 1.1"
